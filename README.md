# Stayly

A modern Airbnb-inspired stay discovery app built with **SwiftUI** for iOS.

Stayly focuses on a clean, simple, and native SwiftUI experience for discovering homes, cabins, villas, and other stays.

## Features

* Search destinations and stays
* Horizontal stay categories
* Categories for:

  * Homes
  * Beach
  * Mountains
  * Cabins
  * Cities
  * Nature
* Property cards with:

  * Property name
  * Location
  * Price
  * Rating
  * Property image
* Clean SwiftUI interface
* Native SF Symbols
* Responsive horizontal scrolling
* Light and dark mode support

## Getting Started

1. Clone the repository.

```bash
git clone https://github.com/your-username/Stayly.git
```

2. Open the project in Xcode.

3. Select an iOS Simulator or connected iPhone.

4. Press **Run** (`⌘R`).
